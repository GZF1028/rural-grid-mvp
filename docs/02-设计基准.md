# 数字乡村网格化后台 —— 设计基准（docs/02）

> 本页是「选定并修正后的设计基准」，前端高保真还原以此为唯一依据。
> 来源：生图 Prompt（assets/design/prompts.md）＋ 4 张采用图视觉复核 ＋ 用户主方向偏好 ＋ 01-需求收敛。

## 0. 方向选择（经 4 张采用图视觉复核后定稿）

**主方向 = 方向 A 的配色与乡村气质 + 方向 B 的简洁布局原则（取长补短）。**

视觉复核结论：
- **干净清晰**：方向 B 略优。尤其地图页，B-1 只保留「网格列表 + 地图 + 图例 + 网格信息」，明显比 A-1 右侧堆叠「天气 / 今日概览 / 快捷操作」更清爽。
- **有乡村感**：方向 A 明显更优。暖白背景 + 田野绿 + 稻穗金 + 田园装饰与「数字乡村」标语，温度感和乡土气息更强；B 的深墨绿偏现代 SaaS，乡村感弱。
- **结论**：不二选一，而是——**用 A 的暖白 + 田野绿 + 稻穗金做主色与气质；地图页布局采用 B-1 的极简版（去掉 A-1 的天气/概览/快捷操作等冗余卡片）；详情页采用 B-2 的分段式（左档案卡 + 右时间线 + 空状态）。** 这样同时满足「干净清晰」与「有乡村感」两条标准。

> 方向 B 图（B-1/B-2）正式作为「布局简洁度」参照保留；配色不切换。

|---|---|---|

| 主色 hover | primary-dark | #2F6B3A |
| 辅助 | accent 稻穗金 | #C9A227 |

| 卡片 | card 白 | #FFFFFF |
| 文字 | ink 深墨 | #1F2A24 |
| 次级文字 | ink-secondary | #5C6B63 |
| 边框 | line | #E3DDD0 |
| 风险·高 | risk-high | #C0392B |

| 风险·低 | risk-low | #3E7C4F |

徽标规则：风险/状态徽标 = 对应色 **10% 透明底 + 100% 文字色**（如 `bg-risk-high/10 + text-risk-high`）。

## 2. 字号层级

| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| 页标题 | 24px / 32px | 600 | 页面主标题 |
| 卡片标题 | 16px / 24px | 600 | 区块/卡片标题 |
| 表头 | 13px | 600 | 表格表头 |
| 正文 | 14px / 22px | 400 | 表格内容、正文 |
| 辅助 | 12px / 18px | 400 | 标签、徽标、辅助说明 |

## 3. 间距规则

- **基数 8px**，档位：4 / 8 / 12 / 16 / 24 / 32。
- 卡片内边距 24px；区块间距 24–32px；控件间距 12px；表格行内边距 12–16px。

## 4. 圆角

| 元素 | 圆角 |
|---|---|
| 卡片 / 筛选区 | 12px |
| 按钮 / 输入框 | 8px |
| 标签 / 徽标 | 6px |

## 5. 组件状态

- **主按钮**：primary 底白字 → hover 变 primary-dark → active 位移 `translate-y-px` → disabled `opacity-50` + 禁点。
- **次按钮**：白底 1px line 边框 + ink 文字 → hover 变 paper 底 → active 位移 → disabled 灰。
- **输入框**：白底 1px line 边框；focus 边框变 primary + 2px primary/20 外环；error 边框变 risk-high。
- **表格行**：hover 浅绿 #F0F6F1 底。
- **徽标**：浅色底 + 深色文字（风险高红/中橙/低绿；状态同理）。
- **页面态**：空态（居中提示 + 引导动作）、加载（骨架屏）、错误（Toast + 区域重试按钮）、表单校验（字段级错误 + 校验通过前按钮 disabled）。

## 6. 响应式规则

- 桌面 **1280px** 主设计；地图页地图与侧栏约 **4:1**。
- **375px**：筛选收起为抽屉/折叠；表格降级为卡片列表；**无横向滚动**；地图可缩放查看/点选，**编辑仅桌面优先**（触屏拖顶点体验差 + 时间有限）。

## 7. 地图视觉规则

- **容器**：主区全幅，浅色路网底图（非卫星图），圆角 12px + 1px line 边框。
- **图例**：右上角悬浮卡（白底），说明「网格边界 / 选中态 / 编辑态顶点」三种样式。
- **网格边界（正常态）**：30% 半透明填充 + 1.5px 实线描边；三网格色：上河组绿、下河组金、桥头组蓝灰。
- **选中态**：描边加粗至 3px + 填充加深 + 外圈柔和阴影。
- **编辑态**：边界显示 8px 白色顶点圆点（带描边）+ 边中点菱形手柄。
- **保存反馈**：成功 → 绿色 Toast「网格边界已保存」；失败 → 红色 Toast + 可重试；取消 → 恢复原状。

## 8. 不还原项（经读图逐条标注）

1. **非 MVP 内容 / 菜单** → 不还原：
   - A-1 右侧「天气(24°C) / 今日概览(巡查任务·事件上报) / 快捷操作」；
   - A-2 左侧「走访记录 / 帮扶服务 / 健康档案 / 关怀提醒 / 事件管理 / 数据分析 / 系统设置」；
   - B-1 底部「1:24,000 比例尺 / 高斯-克吕格投影 / 全部·自然村·社区 tab / 地图·卫星切换」。
   理由：均超出 01-需求收敛 的 MVP 范围。
2. **重复项** → 去掉：A-1「快捷操作」中「事件上报」出现两次，属生图冗余。
3. **枚举 / 状态文案偏离需求** → 文案以需求为准：
   - A-2 人群类型出现「慢性病患者」→ 改为 独居老人 / 空巢老人 / 留守儿童 / 残障人士 / 其他；
   - A-2 状态「在档 / 在访」→ 改为 正常 / 重点关注 / 待走访。
4. **GIS 精度类** → 不还原：总面积 18.6 km²、比例尺 1:24,000、投影带、地图/卫星切换、底部图层 tab。理由：01 明确不做 GIS 精度/多图层。
5. **装饰插画** → 简化：A-2 左下角「田园房子 / 麦田」插画，任务书要求「避免复杂插画」，简化为极简色块或省略。
6. **真实地名底图** → 保留为装饰底图，但业务文案一律以「上河组 / 下河组 / 桥头组」为准。
7. **文字清晰度**：这 4 张采用图的中文基本清晰（豆包表现较好），未发现严重乱码；被拒的 `豆包A-1-0-map.png` 才有文字不清问题。但通用原则不变：**AI 生图文字一律不得直接作为最终文案，以需求与真实数据为准。**
8. **原则**：布局 / 颜色 / 间距 / 组件结构以本设计基准为准；文案以需求为准。

## 11. 视觉复核记录（逐图分析）

> 由模型读图后记录，作为「设计基准」与后续 docs/03 对比的视觉依据。

**豆包A-1-1-map采用.png（方向A 地图页）**
- 布局：顶部标题栏 + 左侧网格列表(3 项)与网格统计卡 + 中间地图(绿/金/蓝灰三网格，绿色选中) + 右侧图例/天气/今日概览/快捷操作 + 右下当前网格信息 + 工具条(编辑边界/保存/取消)。
- 主色：暖白底、田野绿、稻穗金。
- 信息层级：地图清晰；但右侧三张卡过密，与地图争注意力，未达「干净清晰」。
- 判定：配色/网格表达好；**布局参照 B-1 简化（去掉右侧冗余卡片）**。

**豆包A-2-0map采用.png（方向A 列表页）**
- 布局：顶部导航(重点人群高亮)+左侧菜单+标题/新增+筛选条(搜索+4 下拉+重置/查询)+表格(姓名·网格·人群类型·风险徽标·脱敏手机号·状态·最近走访·操作)+分页。
- 主色：暖白+绿+金。
- 信息层级：清晰紧凑，表格可读性强。
- 判定：**直接采用**（配色+结构），仅按第 8 节修正枚举/菜单文案。

**豆包B-1-0map采用.png（方向B 地图页）**
- 布局：左侧网格列表 + 中间大图 + 工具条 + 右侧仅「图例 / 网格信息」两卡。
- 主色：深墨绿、低饱和，卡片纯白。
- 信息层级：非常干净，地图为绝对主角。
- 判定：**布局样板**（干净度优于 A-1），配色不采用。

**豆包B-2-0-map采用.png（方向B 详情页）**
- 布局：顶部返回/标题/编辑·新增走访；左档案卡(头像·姓名年龄·标签·网格·脱敏手机号·监护人·地址·最近走访+关爱 banner)；右走访时间线(4 条，含摘要/下一步)+右侧空状态示例卡。
- 主色：深墨绿系。
- 信息层级：清晰、留白好、时间线易读。
- 判定：**详情页布局样板**（分段式），配色切换为 A。
