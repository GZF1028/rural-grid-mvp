# 数字乡村网格化后台 —— MVP 需求收敛

> 项目周期：3 个工作日 · 单人 · 前端 + 后端 + 部署
> 本文档为需求收敛基准，后续设计基准（docs/02）与实现均以此为准。

## 1. 项目概述与目标
为村干部/网格员提供一个**无登录、单操作人**的迷你后台，管理「重点人群档案」与「网格范围」，
核心闭环：**筛选档案 → 新增/修改档案 → 查看详情与走访时间线 → 记录走访 → 地图查看并编辑网格边界**，
边界编辑结果真实持久化，且不破坏档案与网格的关联。

## 2. 目标用户与核心使用场景
- **目标用户**：村网格员（日常录入与走访登记）、村干部（演示与查看）。
- **场景 1（高频）**：网格员按"网格 + 风险等级 + 人群类型"筛选出要走访的人，点进详情看最近走访，走访后补一条记录。
- **场景 2（维护）**：新增/修改一份重点人群档案（老人、留守儿童等），儿童无手机号时填监护人手机号。
- **场景 3（演示重点）**：在地图上查看上河组/下河组/桥头组范围，拖拽边界顶点调整范围并保存，刷新后边界仍在、档案仍正确归属原网格。

## 3. MVP 功能清单
1. **档案列表**：关键词搜索（姓名/手机号）+ 筛选（所属网格、风险等级、人群类型、状态）+ 分页。
2. **档案新增/编辑**：表单 + 校验（必填、手机号格式、留守儿童监护人必填）。
3. **档案详情**：基本信息 + 走访记录时间线（独立子表，多条按时间倒序）。
4. **走访记录新增**：时间、方式、走访人、情况摘要、下一步（摘要必填，下一步可空）。
5. **地图页**：三个网格多边形展示 + 图例 + 选中态 + 编辑态（拖顶点/边）+ 保存/取消 + 持久化。
6. 空状态、加载状态、错误状态、表单校验、按钮 hover/active/disabled 全覆盖。
7. 移动端 375px：列表无横向滚动、地图可查看（编辑仅桌面）。

## 4. 不做清单
- 不做登录/权限、多角色、多租户、审计日志。
- 不做短信、文件上传、支付。
- 不做复杂统计报表（仅列表计数/徽标）。
- 不做 GIS 精度、官方行政区划导入、多图层、轨迹、点选定位、面积测算。
- 不做自动风险计算（风险等级手动维护）。

## 5. 关键产品取舍（≥3）
1. **网格边界编辑用"多边形顶点/边拖拽"，不导入真实行政区划/GIS**：口述需求是"边界能拖一拖改一改"，Leaflet + GeoMan 免费开箱即用，3 天不碰 GIS 精度，最贴合且可控。
2. **档案通过 `grid_id` 外键关联网格实体，而非把坐标写进档案**：边界改动只更新 `grid` 表，档案无需迁移，直接满足"改完档案里的网格别乱"。
3. **风险等级用手动枚举（高/中/低），不做自动打分**：无历史数据支撑自动算法，手动 + 颜色徽标直观、可演示、零过度设计。
4. **走访记录独立成 `visit` 子表**：满足"单独记"和多条时间线扩展；并用一条规则（新增走访 → 待走访转正常 + 刷新最近走访时间）形成可演示闭环。

## 7. 数据模型（PostgreSQL，Prisma）
**grid 网格表**
| 字段 | 类型 | 约束 |
|---|---|---|
| id | uuid | PK |
| name | varchar(20) | unique, not null（上河组/下河组/桥头组） |
| bounds | jsonb (GeoJSON Polygon) | not null |
| color | varchar(7) | 展示色 |
| sort_order | int | 显示顺序 |
| created_at / updated_at | timestamptz | 默认 now / 自动更新 |

**person 重点人群档案表（主表）**
| 字段 | 类型 | 约束 |
|---|---|---|
| id | uuid | PK |
| name | varchar(20) | not null |
| gender | enum(男,女) | not null |
| birth_date | date | 可空 |
| category | enum(独居老人,空巢老人,留守儿童,残障人士,其他) | not null |
| grid_id | uuid | FK→grid.id, not null, 索引 |
| phone | varchar(11) | 儿童=监护人手机号；格式 `^1[3-9]\d{9}$` |
| guardian_name | varchar(20) | category=留守儿童 时必填 |
| address | varchar(100) | 可空 |
| risk_level | enum(高,中,低) | not null, 默认 低 |
| status | enum(正常,重点关注,待走访) | not null, 默认 正常 |
| last_visit_at | timestamptz | 冗余缓存，写入 visit 时刷新 |
| notes | text | 可空 |
| created_at / updated_at | timestamptz | |

**visit 走访记录表（子表）**
| 字段 | 类型 | 约束 |
|---|---|---|
| id | uuid | PK |
| person_id | uuid | FK→person.id ON DELETE CASCADE, 索引 |
| visited_at | timestamptz | not null（走访时间） |
| method | enum(上门,电话,视频,其他) | not null |
| visitor | varchar(20) | not null（默认"当前网格员"） |
| summary | text | not null（情况摘要） |
| next_step | text | 可空（下一步） |
| created_at | timestamptz | |

## 8. 状态与流转规则
- `status` 手动设置（正常/重点关注/待走访）。
- **闭环规则**：新增走访记录时，后端自动将该档案 `status` 若为"待走访"置为"正常"，并更新 `last_visit_at` 为该档案所有 visit 中最大的 `visited_at`。
- 列表可用「近 30 天未走访」做派生筛选提示（基于 `last_visit_at`，不新增状态字段）。

## 9. 手机号脱敏规则
- 展示层统一 `138****5678`（保留前 3 后 4，中间 4 位星号）；列表与详情均脱敏。
- 编辑表单回显原值；后端返回原始值，脱敏由前端单一工具函数处理，保证一致。
- 儿童（category=留守儿童）的 phone 语义为**监护人手机号**，`guardian_name` 记录监护人姓名。

## 10. 地图展示与编辑的 MVP 深度
- **做**：Leaflet + GeoMan 渲染三个网格多边形；图例；选中态（描边加粗 + 填充高亮）；点击"编辑边界"进入编辑态（白色顶点 + 边中点手柄拖拽）；保存 `PUT /api/grids/:id` 持久化 bounds；取消恢复原状；保存成功 Toast。
- **取舍理由**：满足"地图能看到 + 边界能拖改 + 改完不破坏档案"即可，拖顶点/边已覆盖"拖一拖改一改"；不碰 GIS 精度/导入/多图层，把时间留给闭环与部署。
- **不破坏档案**：档案只存 `grid_id`，边界修改不触碰 `person` 表。

## 11. 空/加载/错误状态约定
- 空态：列表无数据 → 居中提示 + "暂无档案，点击新增"；走访记录为空 → "暂无走访记录"。
- 加载态：列表/详情用骨架屏；地图加载中显示遮罩。
- 错误态：请求失败 → Toast + 区域"重试"按钮；表单提交失败 → 字段级错误提示。
- 表单校验：姓名/类别/网格/风险/状态必填、手机号格式、留守儿童监护人必填；校验通过前按钮 disabled。
- 按钮三态：hover 变深、active 位移/更暗、disabled 灰底禁点。

## 12. 响应式约定
- 桌面 1280 为主设计。
- **375px**：筛选收起为抽屉/折叠；表格降级为卡片列表，**无横向滚动**；地图可缩放查看（可点选），**编辑仅桌面优先**（触屏拖顶点体验差 + 时间有限，明确不做移动端编辑）。
