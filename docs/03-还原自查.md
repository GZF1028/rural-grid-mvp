# 03-还原自查（设计基准图 vs 实现截图）

> 对比方式：左侧为选定方向的设计基准图（AI 生图），右侧为实际运行实现截图（1440px 桌面 / 375px 移动）。
> 截图工具：`scripts/shots.mjs`（playwright-core + 本机 Edge 无头截图），对比图合成：`scripts/compose_compare.py`。
>
> ⚠️ **对齐口径说明**：设计基准图使用的是 **AI 插画式底图**（田块/村道/河流均为风格化绘制），而实现使用**真实高德地图**，两者存在本质差异，**无法做到严格"像素级"对齐**。因此本对比采用「**观感级 + 可核查**」口径：布局、颜色（hex）、字号、间距、圆角、组件状态均按 `docs/02` 设计令牌实现，并可在右侧截图中核查；底图、卡片增减等差异已在下方差异清单逐条标注，不做"看起来差不多"的模糊结论。

## 四、结论

- **已对齐**：三栏布局、网格列表+搜索+统计、地图三块留缝、气泡标签、图例、当前网格信息、编辑/保存/取消、普通/卫星切换、天气+日期+地区、375px 列表卡片化与无横向滚动。
- **有意差异**：底图用真实高德路网（非 AI 插画）、统计数字用真实种子数据、移除未实现的快捷操作/通知铃铛、今日概览改为真实分布。
- **未修正原因**：AI 插画式底图无法用真实地图 1:1 复刻，属任务允许的取舍范围内。
