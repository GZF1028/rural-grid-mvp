# 06-技术文档（数字乡村网格化后台）

> 线上：https://rural-grid-mvp-production.up.railway.app
> 仓库：https://github.com/GZF1028/rural-grid-mvp
> 形态：无登录、单操作人、真实 PostgreSQL 持久化的迷你后台。

## 1. 项目概述

管理「重点人群档案 + 网格范围」：
- 档案：列表（搜索/筛选/分页）、新增/编辑、详情。
- 走访记录：独立子表，时间线展示；新增后自动刷新最近走访时间并做状态流转。
- 网格地图：三个网格多边形、选中高亮、拖顶点/边中点编辑、保存持久化、普通/卫星底图切换、气泡标签。

## 2. 系统架构

```
浏览器 (React 18 SPA, Vite)
        │  HTTPS
        ▼
Railway 单服务 (Fastify, 监听 process.env.PORT)
   ├─ /api/*  →  Prisma Client  →  PostgreSQL (Neon)
   └─ /*      →  apps/web/dist  (静态资源 + SPA fallback)
```

- **单服务、单 URL**：后端同时托管前端构建产物与 API，避免前后端分域部署的 CORS/配置成本。
- 本地开发时前端走 Vite(5173)、后端走 4000，Vite 代理 `/api → localhost:4000`。

## 3. 技术栈与选型理由

| 层 | 选型 | 理由 |
|---|---|---|
| 前端 | React 18 + Vite + TypeScript + Tailwind CSS | 组件化、构建快、原子类便于对齐设计令牌 |
| 地图 | Leaflet + leaflet-geoman-free + 高德栅格瓦片 | 轻量、免 key、GeoMan 开箱支持多边形编辑 |
| 后端 | Node + Fastify + Prisma + Zod | 启动快、类型安全、Schema 即数据模型、Zod 做入参校验 |
| 数据库 | PostgreSQL（Neon 免费档） | 真实持久化，云端无需本地安装 |
| 部署 | Railway | GitHub 自动部署、单服务、送公开域名 |

## 4. 数据模型（Prisma）

### 4.1 枚举（DB 存英文 key，前端映射中文）

| 枚举 | 值（→ 中文） |
|---|---|
| Gender | MALE(男) / FEMALE(女) |
| PersonCategory | ELDERLY_LIVING_ALONE(独居老人) / EMPTY_NESTER(空巢老人) / LEFT_BEHIND_CHILD(留守儿童) / DISABLED(残障人士) / OTHER(其他) |
| RiskLevel | HIGH(高) / MID(中) / LOW(低) |
| PersonStatus | NORMAL(正常) / KEY_FOCUS(重点关注) / PENDING_VISIT(待走访) |
| VisitMethod | ON_SITE(上门) / PHONE(电话) / VIDEO(视频) / OTHER(其他) |

### 4.2 表结构

**grid（网格）**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | uuid PK | |
| name | varchar unique | 上河组/下河组/桥头组 |
| bounds | jsonb | GeoJSON Polygon（坐标数组） |
| color | varchar | 展示色（#3E7C4F / #C9A227 / #5B7A8C） |
| sort_order | int | 显示顺序 |
| created_at / updated_at | timestamptz | |

**person（重点人群，主表）**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | uuid PK | |
| name | varchar not null | |
| gender | enum | |
| birth_date | date | 可空 |
| category | enum | 人群类型 |
| grid_id | uuid FK→grid.id | **关键：档案只关联网格实体，不存坐标** |
| phone | varchar | 儿童存监护人手机号 |
| guardian_name | varchar | 留守儿童必填 |
| address | varchar | 可空 |
| risk_level | enum 默认 LOW | |
| status | enum 默认 NORMAL | 正常/重点关注/待走访 |
| last_visit_at | timestamptz | 冗余缓存，写入走访时刷新 |
| notes | text | 可空 |

**visit（走访记录，子表）**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | uuid PK | |
| person_id | uuid FK→person.id ON DELETE CASCADE | |
| visited_at | timestamptz | 走访时间 |
| method | enum | 走访方式 |
| visitor | varchar | 走访人 |
| summary | text not null | 情况摘要 |
| next_step | text | 下一步（可空） |

### 4.3 关键约束
- `person.grid_id` 外键，索引；删除网格受引用保护（业务上先迁移档案）。
- 手机号格式 `^1[3-9]\d{9}$`（Zod + 接口双重校验）；留守儿童 `guardian_name` 必填。
- 走访写入后：`last_visit_at` = 该人所有走访的最大 `visited_at`；`PENDING_VISIT → NORMAL`。

## 5. 后端设计

### 5.1 分层
```
src/
├─ index.ts        # 创建 Fastify、注册 cors/static、挂载路由、监听 PORT
├─ db.ts           # PrismaClient 单例
└─ routes/
   ├─ grids.ts     # GET /api/grids、PUT /api/grids/:id
   ├─ persons.ts   # 列表/详情/新增/修改
   └─ visits.ts    # 走访列表/新增（含状态闭环）
```

### 5.2 校验（Zod）
- `listQuery`：q / gridId / riskLevel / category / status / page / pageSize（coerce）。
- `personBody`：姓名必填、枚举、gridId、手机号、监护人等。
- `visitBody`：visitedAt / method / visitor / summary 必填。
- `polygonSchema`：`{ type: "Polygon", coordinates: number[][][] }`。

### 5.3 错误处理
- 校验失败 → `400 { error, details }`；
- 资源不存在 → `404 { error }`；
- 未捕获异常 → Fastify 默认 `500`（线上不泄露堆栈）。

### 5.4 走访闭环（核心业务规则）
`POST /api/persons/:id/visits` 成功后：
1. 重新计算该人最近一次走访时间；
2. 更新 `person.last_visit_at`；
3. 若原状态为 `PENDING_VISIT`，改为 `NORMAL`。

### 5.5 静态托管（单服务）
- `@fastify/static` 托管 `apps/web/dist`（prefix `/`）；
- `setNotFoundHandler`：`/api/*` 返回 404 JSON，其余回 `index.html`（SPA fallback）。

## 6. API 文档

| 方法 | 路径 | 说明 | 参数/请求体 |
|---|---|---|---|
| GET | `/api/health` | 健康检查 | — |
| GET | `/api/grids` | 网格列表（含 `_count.persons`） | — |
| PUT | `/api/grids/:id` | 更新网格 | `{ bounds?, color?, name? }` |
| GET | `/api/persons` | 档案列表 | query：`q, gridId, riskLevel, category, status, page, pageSize` |
| GET | `/api/persons/:id` | 档案详情（含 grid + visits） | — |
| POST | `/api/persons` | 新增档案 | person 字段 |
| PUT | `/api/persons/:id` | 修改档案 | person 字段 |
| GET | `/api/persons/:id/visits` | 走访列表 | — |
| POST | `/api/persons/:id/visits` | 新增走访（触发闭环） | `{ visitedAt, method, visitor, summary, nextStep? }` |

**列表返回**：`{ items: Person[], total: number, page, pageSize }`（`orderBy: lastVisitAt desc nulls last, createdAt desc`）。

**PUT /api/grids/:id 请求示例**
```json
{ "bounds": { "type": "Polygon", "coordinates": [[[119.639,30.687],[119.643,30.69], ...]] } }
```

## 7. 前端设计

### 7.1 目录
```
src/
├─ main.tsx / App.tsx      # 入口 + 状态路由（list/detail/form/map）
├─ api.ts                  # fetch 封装 + ApiError + 查询串
├─ types.ts                # 类型定义（与后端枚举一致）
├─ lib/format.ts           # 枚举→中文、maskPhone、age、birthDateFromAge、日期格式化
├─ components/             # Layout / Badges / States / Modal / VisitModal
└─ pages/                  # PersonList / PersonDetail / PersonForm / MapPage
```

### 7.2 路由
单页状态路由（`useState<View>`），`View = list | detail(id) | form(id?) | map`；顶栏切换档案列表/网格地图。

### 7.3 设计令牌（Tailwind）
- 颜色：primary `#3E7C4F`、primary-dark `#2F6B3A`、accent `#C9A227`、paper `#FAF7F0`、ink `#1F2A24`、ink-secondary `#5C6B63`、line `#E3DDD0`、risk-high `#C0392B`、risk-mid `#D98A2B`、risk-low `#3E7C4F`。
- 圆角：card 12px / control 8px / tag 6px。
- 字号：page-title 24 / card-title 16 / body 14 / caption 12。
- 组件类：`.btn-primary` / `.btn-secondary` / `.input` / `.select`（含 hover/active/disabled/focus）。

### 7.4 交互与状态
- 列表：查询/重置/分页；空态、骨架屏、错误重试。
- 表单：必填校验、手机号格式、留守儿童监护人；保存中禁用按钮。
- 脱敏：`maskPhone` 展示 `138****1246`。
- 响应式：`sm` 断点表格↔卡片；地图三栏 `lg` 断点以下堆叠。

## 8. 地图实现（MapPage）

### 8.1 结构
- refs：`containerRef`、`mapRef`、`polygonsRef`、`originalRef`、`normalTileRef`、`satelliteTileRef`。
- state：`grids`、`selectedId`、`editing`、`saving`、`loading`、`error`、`toast`、`search`、`basemap`。

### 8.2 初始化（依赖 `loading`）
- `L.map(container)` + `L.control.zoom({ position: "bottomleft" })`；
- 普通底图：高德 `webrd` `style=8`；卫星底图：`webst` `style=6`（`className: "amap-tile"` 提对比/饱和）。
- **关键坑**：容器在 `loading` 时被骨架屏替换，init effect 必须依赖 `loading`，等容器渲染后再初始化。

### 8.3 渲染多边形（核心逻辑）
- `L.polygon(toLatLngs(bounds), { color, weight:2, fillColor, fillOpacity:0.34 })`；
- 点击选中（编辑态禁用切换）；
- 气泡标签：`poly.bindTooltip('<span class="grid-label-pill" style="background:...">名称</span>', { permanent, direction:"center", interactive:false })`；
- 首次 `fitBounds(pad(0.12))`。

### 8.4 选中态
`setStyle`：选中 weight 3.5 / fillOpacity 0.48，并 `bringToFront()`。

### 8.5 编辑（GeoMan）
- 进入编辑：`poly.pm.enable({ allowSelfIntersection: false })`，先存原 bounds；
- 取消：`poly.setLatLngs(原 bounds)`；`poly.pm.disable()`。

### 8.6 保存
- `getGeoJson(poly)` → `PUT /api/grids/:id` → 更新本地 grids → 关闭编辑 → Toast「网格边界已保存」；
- 失败：红色 Toast。

### 8.7 底图切换
`basemap` 状态切换：移除当前瓦片、添加另一套（普通/卫星）。

### 8.8 面积统计
球面多边形面积公式，按网格 bounds 求和，展示「总面积 xx km²」（随编辑保存变化）。

## 9. 部署（Railway）

### 9.1 配置
- `railway.json`：`buildCommand: pnpm install && pnpm run build:deploy`；`startCommand: node apps/server/dist/index.js`。
- `.nvmrc` = 22；根 `engines.node >= 20`。

### 9.2 构建
- `build:deploy` = `pnpm --filter web build && pnpm --filter server build`；
- **server build = `prisma generate && tsc`**（否则 Railway 上 `@prisma/client` 只装空壳，类型全缺）。

### 9.3 环境变量
- `DATABASE_URL`：Neon 连接串（**去掉 `channel_binding`**，否则 Prisma 解析失败）；
- `PORT`：Railway 自动注入。

### 9.4 数据库
- 本地已对 Neon 执行 `prisma db push` + `db seed`（3 网格/10 人/8 走访）；
- 线上仅需 `DATABASE_URL` 指向同一库。

## 10. 本地开发

- `apps/server/.env`：`DATABASE_URL=...`。

## 11. 已知限制与改进方向

| 限制 | 说明 / 改进 |
|---|---|
| 地图底图 | 高德瓦片为**免 key 非官方用法**，生产应换官方 SDK + Key（或天地图/腾讯） |
| 边界精度 | 手绘演示坐标，未贴合真实道路/田埂；可接入行政区划或人工描图 |
| 移动端编辑 | 桌面优先，未做触摸拖拽；可补表单化编辑 |
| 自动化测试 | 目前靠 build + 脚本截图 + 手工验收；可补 Playwright E2E |
| 设计还原 | 观感级而非像素级（AI 插画底图 vs 真实地图，见 docs/03 说明） |
