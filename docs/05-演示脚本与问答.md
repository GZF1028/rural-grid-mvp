# 05-演示脚本与问答（5 分钟）

> 线上地址：https://rural-grid-mvp-production.up.railway.app
> 适用：试岗/答辩现场演示

## 一、演示前准备（2 分钟）
1. **预热**：打开 `https://rural-grid-mvp-production.up.railway.app/api/health`，看到 `{"ok":true}` 即已唤醒（免费实例会休眠，冷启动慢）；再打开首页等列表出数据。
2. 准备两个标签页：档案列表、网格地图。
3. 确认高德瓦片能加载（地图有底图即可，多边形不依赖底图）。
4. 预热后**别关标签页**，演示时直接切过去。

## 三、演示小技巧
- 地图页底图慢时先等 1–2 秒，重点讲"多边形和编辑"，不要卡在底图加载。
- 若网络差，直接说"多边形是业务图层，不依赖底图"。

## 四、常见追问与答法

| 追问 | 答法 |
|---|---|
| 为什么不做登录/权限？ | 任务明确不要求；MVP 默认当前网格员，省下的时间投到地图编辑与后端闭环。 |
| 快捷操作/通知铃铛怎么没了？ | 它们不是 MVP、点了也没功能，按"不实现即不显示"移除，避免假按钮。 |
| 地图为什么用 Leaflet+瓦片，不用高德官方 SDK？ | 试岗优先闭环：官方 SDK 要实名 Key + 重写地图引擎；瓦片零成本可演示，生产会换官方 SDK+Key。 |
| 改边界为什么档案不会乱？ | 档案只存 `grid_id` 外键，边界改动只更新 `grid` 表，二者解耦。 |
| 手机号怎么脱敏？ | 前端统一工具函数展示 `138****1246`；儿童存监护人手机号 + 监护人姓名。 |
| 状态怎么流转？ | 手动设 正常/重点关注/待走访；新增走访后 待走访→正常 并刷新最近走访时间。 |
| 375px 怎么处理的？ | 列表表格降级为卡片、无横向滚动；地图可展示，编辑桌面优先（已说明）。 |
| AI 怎么用的？ | 豆包生图定设计基准 + AI 编码；靠 docs/01-02 喂上下文、build/实测/截图设门禁、人拍板取舍。 |
| 数据怎么持久化？ | PostgreSQL（Neon）+ Prisma；`db push` 建表、`seed` 灌数据。 |
| 如果继续做会加什么？ | 真实行政区划/人工描图、官方地图 SDK、移动端编辑、E2E 测试。 |
| Neon / Railway 分别是什么？ | **Neon** = 云数据库（存数据）；**Railway** = 部署平台（跑代码 + 给公网 URL）；Railway 用 `DATABASE_URL` 连 Neon。 |
| 关掉 Neon/Railway 网页会停吗？怎么预热？ | 不会，网页只是控制台；演示前打开 `/api/health` 预热一次即可；长期无访问会休眠，有访问自动唤醒。 |
