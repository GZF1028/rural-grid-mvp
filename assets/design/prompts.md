# 生图 Prompt 模板（A/B 两方向 × 4 张）

> 使用说明：每个方向 2 张图，共 4 张。豆包与 GPT-4o 可复用同一段 Prompt（GPT-4o 出布局更干净，豆包中文占位更好）。
> 每张生成后**单独保存原图**到 `assets/design/`，并记录：模型、prompt、生成时间、选/弃理由。
> 生成的中文文字若乱码/错字 → 一律记为"不还原项"，文案以需求为准，布局/配色/间距/组件结构以设计基准为准。
> 每个方向至少保留一条"拒绝采纳 AI 生图输出"的记录（说明原因）。

**方向 A（田野生机绿 · 稻穗金 · 暖白）vs 方向 B（深墨绿 · 低饱和青绿 · 现代 SaaS）**：颜色不同、圆角更小、留白更多，形成"实质差异"。

---

【A-1 地图展示/编辑页 · 田野生机绿方向】

请生成一张「数字乡村网格化管理后台」的网格地图展示与边界编辑页面的 UI 设计图（Web 桌面端，横屏）。

页面类型：后台管理系统的地图页。
布局结构（左中右）：
- 左侧窄栏：网格列表（上河组/下河组/桥头组三项，各带颜色圆点+网格名+档案数），当前项高亮。
- 中间主区：地图画布占主面积，浅色路网底图（非卫星图），上方悬浮工具条（编辑边界/保存/取消）。
- 右上悬浮图例卡：说明"网格边界 / 选中态 / 编辑态顶点"三种样式。
- 右下悬浮信息卡：当前网格名称 + 该网格重点人群数。
组件清单：侧栏列表项、地图容器、三个不规则多边形边界（上河组绿/下河组金/桥头组蓝灰）、可拖拽白色顶点、边中点手柄、工具条按钮、图例卡、信息卡、标题栏。
视觉规范：
- 主色 田野绿 #3E7C4F，辅助 稻穗金 #C9A227，背景 暖白 #FAF7F0，文字 深墨 #1F2A24，次级 #5C6B63，边框 #E3DDD0。
- 多边形正常态=30% 半透明填充+1.5px 描边；选中态=描边 3px+填充加深+柔和阴影；编辑态=8px 白色顶点圆点+边中点菱形手柄。
- 圆角：卡片 12px、按钮/输入 8px、标签 6px；间距 8px 基数；字号：标题 24px 粗、卡片题 16px 粗、正文 14px、辅助 12px。
- 主按钮绿色底白字，hover 变深，disabled 灰底。
状态要求：同时体现"一个网格选中态、一个编辑态（带顶点）、一个普通态"三种对比。
响应式意图：桌面为主，信息密度中等，地图与侧栏约 4:1。
输出要求：横屏桌面 UI，扁平、无大面积渐变、无复杂插画、无真人照片；文字可占位/近似，重点是布局/配色/组件/状态清晰。

【A-2 档案列表页 · 田野生机绿方向】

请生成一张「数字乡村网格化管理后台」的重点人群档案列表页 UI 设计图（Web 桌面端，横屏）。
页面类型：后台数据列表页。
布局结构（自上而下）：
- 顶部：左标题"重点人群档案"，右主按钮"+ 新增档案"（绿色底）。
- 筛选区：搜索框（占位"搜索姓名/手机号"）+ 下拉(所属网格/风险等级/人群类型/状态) + "重置/查询"按钮。
- 表格：列=姓名(含性别年龄小字)/所属网格/人群类型/风险等级(彩色徽标)/手机号(脱敏)/状态/最近走访时间/操作(查看·编辑)；行 hover 浅色底。
- 底部分页器(上一页/页码/下一页 + 共 N 条)。
组件清单：标题、主按钮、搜索框、4 个下拉、重置/查询、表头/数据行/hover 行、风险徽标(高红/中橙/低绿)、状态徽标、脱敏手机号、操作按钮、分页器。
视觉规范：
- 主色 #3E7C4F，辅助 #C9A227，背景暖白 #FAF7F0，卡片白 #FFFFFF，文字深墨 #1F2A24，次级 #5C6B63，边框 #E3DDD0。
- 风险徽标：高 #C0392B 浅红底、中 #D98A2B 浅橙底、低 #3E7C4F 浅绿底，圆角 6px，字号 12px。
- 圆角：卡片/筛选区 12px、按钮/输入 8px；间距 8px 基数；字号：标题 24px、表头 13px 粗、正文 14px、辅助 12px。
状态要求：至少 8 行示例数据，混合不同风险/网格/状态；单独示意一行 hover 态(行背景浅绿 #F0F6F1)。
响应式意图：桌面为主，信息密度中等。
输出要求：扁平、无大面积渐变、无复杂插画；文字可占位，重点在表格/徽标/配色/hover 态。

【B-1 地图展示/编辑页 · 深墨绿现代方向】

请生成一张「数字乡村网格化管理后台」的网格地图展示与边界编辑页面 UI 设计图（Web 桌面端，横屏），风格偏现代简洁 SaaS。
页面类型：后台地图页。
布局结构：左侧窄栏网格列表 + 中间地图画布(工具条：编辑边界/保存/取消) + 右上图例卡 + 右下信息卡。
组件清单：侧栏列表项、地图容器、三个多边形边界(绿/金/蓝灰)、可拖拽白色顶点、边中点手柄、工具条、图例卡、信息卡、标题栏。
视觉规范：
- 主色 深墨绿 #16302B，辅助 低饱和青绿 #2E6E63，点缀 暖橙 #C98A3D，背景 浅灰绿 #F4F6F4，卡片纯白 #FFFFFF，文字 #17201C，次级 #5A6B63，边框 #DFE5E1。
- 多边形正常态=淡色填充+1px 描边；选中态=2.5px 描边+浅阴影；编辑态=白色顶点+边中点手柄。
- 圆角：卡片 8px、按钮/输入 6px、标签 4px；间距 8px 基数；字号：标题 22px 粗、正文 14px、辅助 12px。
- 更扁平、留白更多，接近 Linear/Notion 的现代简洁感。
状态要求：同时体现选中态/编辑态/普通态三种对比。
响应式意图：桌面为主，地图与侧栏约 4:1。
输出要求：横屏桌面 UI，扁平、无大面积渐变、无复杂插画；文字可占位，重点是现代简洁的配色与组件状态。

【B-2 档案详情+走访时间线页 · 深墨绿现代方向】

请生成一张「数字乡村网格化管理后台」的重点人群档案详情页（含走访记录时间线）UI 设计图（Web 桌面端，横屏），现代简洁风格。
页面类型：后台详情页。
布局结构：
- 顶部：返回按钮 + 标题"档案详情" + 右侧"编辑档案 / + 新增走访"按钮。
- 左/上：档案概要卡——头像占位圆、姓名+性别年龄、人群类型标签、风险等级徽标、状态徽标、所属网格、脱敏手机号、监护人、地址、最近走访时间。
- 右/下：走访记录时间线——左侧竖线+圆点节点，最新在顶；每条含(时间/方式/走访人 + 情况摘要 + 下一步)。
组件清单：返回按钮、主/次按钮、概要卡、头像占位、人群标签、风险徽标、状态徽标、脱敏手机号文本、时间线(竖线+节点)、空状态占位。
视觉规范：
- 主色 深墨绿 #16302B，辅助 青绿 #2E6E63，点缀 暖橙 #C98A3D，背景 #F4F6F4，卡片白 #FFFFFF，文字 #17201C，次级 #5A6B63，边框 #DFE5E1。
- 风险徽标：高红 #C0392B、中橙 #D98A2B、低绿 #2E6E63，浅色底、圆角 4px、字号 12px。
- 圆角：卡片 8px、按钮/输入 6px、标签 4px；间距 8px 基数；字号：标题 22px、正文 14px、辅助 12px。
状态要求：时间线 3~4 条示例；另单独示意"时间线为空"的空状态。
响应式意图：桌面为主，现代简洁、留白充足。
输出要求：横屏桌面 UI，扁平、无大面积渐变、无复杂插画；文字可占位，重点是信息卡与时间线层次。
